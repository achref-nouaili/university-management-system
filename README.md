# university-management-system
## Project Description

The **University Management System** is a web-based application designed to simplify and centralize the management of academic and administrative activities within a university.

The platform provides a unified environment where students, teachers, and administrative staff can access and manage information according to their roles and permissions.

Its main purpose is to improve communication, facilitate academic follow-up, and make university administrative processes more efficient.

## Main Objectives

- Centralize academic and administrative information.
- Simplify the management of courses and timetables.
- Facilitate grade and attendance management.
- Improve communication between students, teachers, and administration.
- Provide secure access based on user roles.

## Main Features

- **Authentication and Authorization:** Secure login and role-based access control.
- **User Management:** Manage students, teachers, and administrative accounts.
- **Timetable Management:** Publish and update university timetables.
- **Grade Management:** Allow teachers to enter grades and students to consult their results.
- **Attendance Management:** Record and track student absences.
- **Notifications:** Notify students about timetable changes and newly published grades.
- **Course Information:** Provide access to course details and learning materials.
- **Administrative Requests:** Submit and track requests for certificates and academic transcripts.
- **Official Announcements:** Publish important university announcements.
- **University Activities:** Allow students to register for university activities.
- **Statistics Dashboard:** Display statistical information about academic activities.

## Technologies

The proposed technology stack:

- **Frontend:** React.js
- **Backend:** Spring Boot
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub
- **API Testing:** Postman

## User Roles

The system supports three main categories of users:

- **Student:** Consult timetables, grades, absences, courses, announcements, and submit administrative requests.
- **Teacher:** Manage grades, record attendance, and publish course materials.
- **Administrator:** Manage users, timetables, administrative requests, and official announcements.
